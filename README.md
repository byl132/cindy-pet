# Cindy 桌宠（Q版）

启动：双击 `start.bat`，或 `npm start`。

## 交互
| 操作 | 效果 |
|---|---|
| 在头上来回摸（rua） | 开心 + 爱心特效，涨好感度 |
| 单击 | 被戳的反应 |
| 双击 | 打开聊天面板 |
| 按住拖动 | 拎起来，松手后会落回屏幕底部 |
| 右键 | 菜单：聊天 / 切换 AI 角色 / 自动行走 / 睡觉 / 设置 / 退出 |
| 空闲 | 自动在屏幕底部左右行走；5 分钟无互动会睡着 |

## 情绪价值
- 开机问候（按时段）、定时关怀（喝水/活动/吃饭/熬夜提醒，间隔可调）。
- 聊天时 AI 会共情、鼓励；未配置 API 时用本地关键词兜底（累、难过、完成了…）。

## AI 角色联动
右键 → 设置：填写 OpenAI 兼容接口（Base URL / Key / 模型），并可添加多个角色（各自 Prompt，可指定不同模型）。

## Cindy 联动（本地接口 127.0.0.1:47831）
```
curl -X POST http://127.0.0.1:47831/say   -d "{\"text\":\"你好\",\"mood\":\"happy\"}"
curl -X POST http://127.0.0.1:47831/event -d "{\"type\":\"task_done\",\"title\":\"整理文档\"}"   # 或 task_failed
curl http://127.0.0.1:47831/ping
```
可在设置里配置 Token（请求体 `token` 字段或 `X-Token` 头）。

## 素材
`assets/`：6 个姿势 + 4 帧行走（透明 PNG）；原图在 `raw/`，切图脚本 `tools_slice.py`。

## v0.2 新增
- **跟随 Cindy**：右键 → 跟随 Cindy。桌宠在托盘待命，Cindy.exe 运行时自动出现，Cindy 退出后自动隐藏。建议同时勾选“开机自动启动”。
- **系统链接** `cindy-pet://show`、`hide`、`panel/mood`、`say?text=你好`（安装版会注册）。
- **面板**（右键 → 面板，或托盘菜单）：状态（心情/精力/好感度等级/统计）、心情打卡（14 天曲线）、专注计时、提醒。
- **趴在屏幕边上**：右键 → 趴在屏幕边上（上/下/左/右），四套衣服各有一份素材；把桌宠拖到屏幕上沿或左右边缘松手也会趴上去；空闲时会自己偶尔趴一会儿。
- **任何位置**：松手后留在原地（默认无重力）；右键可开启“重力”。
- 心情/精力会随互动和时间变化，并影响台词与行为。
- 安装包：`npm run dist` → `dist/Cindy桌宠 Setup 0.2.0.exe`（未签名，Windows 可能提示“未知发布者”）。

## v0.5 新增：macOS 版 + 动作同步
- **动作同步**：Cindy 里的桌宠页面和桌面版之间，手动触发的动作（坐下、伸懒腰、抱猫、欢呼等）、rua、睡觉/叫醒会在两边同时发生；远端触发的不会回传，不会循环。两边“与桌面版同步”开启时生效，设置与动作都走同一条通道。
- **macOS 版**：代码已适配菜单栏图标、置顶、可见于所有桌面与全屏、系统链接、跟随 Cindy（`pgrep`）。构建方式和注意事项见 `MAC.md`（本机是 Windows，无法本地构建 macOS 包，可用 `scripts/build-mac.sh` 或 GitHub Actions）。

## v0.4 新增：跟着任务工作，看得到项目与用量
- **跟着 Cindy 工作**：Cindy 在干活时桌宠坐下打字/看书，思考时托腮，等你确认或回答时举手，出错时抱头，做完欢呼；预算快用完时会累趴。四套衣服都有对应姿势。
- **用量与预算**：旁听每一轮的 token 用量（不含对话内容），按你自设的每日/每月预算估算剩余（Cindy 不向插件开放真实剩余额度）。
- **项目概览**：你亲手选择的项目文件夹，只读统计文件数、语言占比、TODO/FIXME、最近改动、Git 分支与最近提交（不上传、不读源码内容）。
- **任务看板**：显示当前项目的任务状态（需 Cindy 开放观察接口）。
- 桌面版右键 → 面板 → 工作台；其他 AI（Claude Code / Codex）用 `integrations` 里的钩子也能让桌宠跟着干活。

## v0.3 新增
- **其他 AI 接入**：`integrations/` 提供 MCP 服务（Claude Code / Codex / Cursor / Cline / Windsurf）、命令行、Claude Code 钩子与 Codex 通知配置，详见 `integrations/README.md`；`GET /api` 返回接口说明。
- **更多模型**：设置里一键预设 OpenAI、DeepSeek、Anthropic Claude、Google Gemini、Ollama、LM Studio；本机地址可不填 Key。
- **与 Cindy 插件双向同步**服装、角色、称呼（以最后修改时间为准，自动对账）。
- **四边趴边**（上/下/左/右），四套衣服各有素材；拖拽时按方向镜像的“被拎起”姿势；松手留在原地（默认无重力）。
