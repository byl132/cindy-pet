# 桌宠联动

住在 Cindy 里的 Q 版桌宠，另有可选的桌面版。

## 在 Cindy 里
打开左侧“桌宠”页面：它会走来走去，可以 rua（在头上来回摸），用你的 Cindy 模型聊天，给情绪价值和温柔提醒；支持 4 套服装，每套都有 6 个动作。

## Agent 工具
- `pet_say`：任务完成播报、鼓励、提醒休息
- `pet_action`：坐下 / 伸懒腰 / 抱黑猫 / 趴着睡 / 欢呼 / 喝热饮
- `pet_outfit`：换装
- `pet_dock`：让桌面版桌宠趴到屏幕上/下/左/右边缘
- `pet_show`：显示或隐藏桌面版
- `pet_work_status`：Cindy 的工作状态、用量与剩余预算、项目概览、任务状态
- `pet_set_budget`：设置每日/每月 token 预算，并验算剩余估算
- `pet_project_scan`：重新扫描你选择的项目文件夹
- `pet_status`：检查桌面版与聊天中继是否在线

## 桌面版（可选，单独安装包）
透明置顶的桌面桌宠：心情/精力系统、面板（状态、心情打卡、专注计时、提醒）、趴在屏幕边上、被拎起移动、托盘图标，并提供 Windows 安装包。
- 右键 → “跟随 Cindy”：Cindy 运行时桌宠自动出现，Cindy 退出后自动隐藏（再勾选“开机自动启动”即可全自动）。
- 桌面版设置 → 对话来源 → Cindy 模型：桌面桌宠通过你的 Cindy 模型聊天（需保持 Cindy 里的桌宠页面打开）。
- 本插件会把播报、动作、换装转发给它。

## 与其他 AI 工具一起用
桌面版自带 MCP 服务（`deskpet-mcp.cjs`）、命令行（`deskpet-cli.cjs`）以及 Claude Code / Codex / Cursor 的现成配置（`integrations` 文件夹），其他 AI 也能让桌宠播报任务结果、做动作、换装、趴边。

## 跟着 Cindy 的任务活动工作
桌宠会跟着 Cindy 的状态动：工作（打字/看书）、思考、等你确认/回答（举手）、出错、做完（欢呼），只使用活动边界和 token 数量，不接触对话、命令或文件内容。“工作台”面板显示今日/本月用量与按你自设预算估算的剩余（Cindy 不向插件开放真实剩余额度）、你亲手选择的项目文件夹概览（只读统计）和项目任务状态。

## 动作同步
开启“与桌面版同步”后，手动触发的动作（坐下、伸懒腰、抱猫、欢呼等）、rua、睡觉/叫醒会在 Cindy 页面和桌面版（Windows / macOS）之间同时发生；远端触发的动作不会回传，不会循环。

## 隐私
- **本地通信**：插件只访问你电脑上的 `127.0.0.1`（桌面版 47831、中继 47832），不会把数据发到插件作者的服务器。
- **桌宠聊天**：你在 Cindy 里和桌宠聊天时，插件会把以下内容交给 Cindy，再由 Cindy 发给你在 Cindy 里选择的模型：桌宠的角色设定、最近 16 条聊天记录、Cindy 当前的工作状态（空闲 / 工作中 / 思考中 / 等你确认 / 出错），以及设置了预算时的用量百分比。如果所选模型是在线服务，这些文字会发送给该模型服务商。
- **不会发送**：项目文件内容、文件名、歌名或视频标题。项目文件夹只有在你亲手选择后才会被只读统计，统计结果只保存在本地。
- **桌面版**：插件不会自动下载或安装桌面版。请到官方页面自行安装，插件只在本机与其联动。
